## 계약 1 — 자료형 · 인터페이스 (`RPi/pi/contracts.py`)

```python
from typing import TypedDict, Literal, Protocol, Callable

# ── 자료형 ──
class Sample(TypedDict):
    t_ms: int                       # millis 타임스탬프
    ax: int; ay: int; az: int       # 가속도 raw(LSB), ±8g → 4096 LSB/g
    gx: int; gy: int; gz: int       # 자이로 raw(LSB), ±500dps → 65.5 LSB/dps
    wheel_pulse: int                # 엔코더 누적 펄스(단조증가 스냅샷)

RoadClass = Literal["asphalt", "bike_path", "sidewalk_block", "concrete", "gravel"]
Mode = Literal["IDLE", "COLLECT", "DEMO"]

# ── 서브시스템 인터페이스(Protocol) — 각 파트가 구현, 통합이 소비 ──
class Motor(Protocol):              # ① (DJ)
    def set_duty(self, duty: float) -> None: ...   # 0.0~1.0 직진
    def stop(self) -> None: ...

class Encoder(Protocol):            # ②③ 공유 (DJ 소유, 단일 인스턴스 주입)
    def pulses(self) -> int: ...                   # 누적 펄스
    def speed_mps(self) -> float: ...              # 현재 속도 m/s

class SpeedController(Protocol):    # ② (DJ)
    def set_target(self, speed_mps: float) -> None: ...
    def update(self) -> None: ...                  # 주기 호출: 엔코더→Motor 보정
    def stop(self) -> None: ...

class Sampler(Protocol):            # ③ (CW)
    def start(self) -> None: ...                   # FIFO drain+엔코더 → sample_queue
    def stop(self) -> None: ...

class Logger(Protocol):             # ③ (CW)
    def open(self, label: str) -> None: ...
    def write(self, s: Sample) -> None: ...
    def close(self) -> None: ...

class Windower(Protocol):           # 인지 (CW)
    def add(self, s: Sample): ...                  # -> Window | None

class Model(Protocol):              # 인지 (CW)
    def predict(self, window) -> RoadClass: ...

class BleServer(Protocol):          # ④ (CW)
    def on_command(self, cb: Callable[[dict], None]) -> None: ...
    def send_telemetry(self, data: dict) -> None: ...
    def start(self) -> None: ...

# policy(road: RoadClass) -> float   # 목표 속도(m/s)
```

> DJ 초안 대비 추가: **`Encoder` 프로토콜**(공유 명시) · **`Windower`/`Model`**(인지) · 단위 주석.

## 계약 2 — 앱↔Pi 통신 프로토콜 (RFCOMM · JSON) — ✅ 확정 2026-08-14 (issue #10 종결)

> **앱(도현)이 완성되어 있으므로 Pi가 앱 규격에 맞춘다.** 결정: 파일관리 Pi 지원 · 라벨링=수집 후 RENAME · 자전거도로 추가 · 단위 환산은 앱.

### 전송 계층
- **Bluetooth Classic RFCOMM (SPP)** — UUID `00001101-0000-1000-8000-00805F9B34FB`
- **줄 단위 JSON**(UTF-8, `
` 종단). Pi = RFCOMM 서버, 앱 = 클라이언트
- ~~BLE GATT(bluezero)~~ 폐기 → `bluezero` 의존성 제거

### 명령 (앱 → Pi) — 앱 `RpiProtocol.build*` 그대로
```json
{"cmd":"SET_MODE","mode":"COLLECT"}          // 대문자. COLLECT | DEMO (IDLE에서만)
{"cmd":"START"}
{"cmd":"STOP"}
{"cmd":"LIST_FILES"}                         // → FILES 응답
{"cmd":"RENAME","old":"run_0001.csv","new":"run_0001_자갈길_건조.csv"}
{"cmd":"MEMO","file":"run_0001.csv","memo":"..."}
```
- ~~`SET_LABEL`~~ 폐기 — **라벨은 수집 후 `RENAME`으로 파일명에 부여**(앱 파일탭 UX 유지)
- 파일명 규칙(앱 `buildNewFileName`): `<원본>_<노면>_<상태>.csv`

### 응답 (Pi → 앱) — `type` 필드로 구분
```json
{"type":"ACK","cmd":"START","ok":true}
{"type":"ERROR","cmd":"RENAME","message":"파일 없음"}
{"type":"FILES","files":["run_0001.csv","run_0002_아스팔트_건조.csv"]}
{"type":"STATUS","speed":0.4,"distance":12.3,"vibration":0.08,"roadType":"자갈길"}
```
- **모든 명령에 `ACK`(성공) 또는 `ERROR`(실패)** 응답
- `STATUS`는 주기 송신(5Hz). 필드:
  - `speed` — **m/s 원값**. 앱이 km/h 등으로 환산·표시 (결정 4)
  - `distance` — 누적 m (엔코더)
  - `vibration` — 최근 윈도우 진동 RMS(raw LSB, DC 제거) — 앱 표시용
  - `roadType` — 아래 노면 표시명(한글). 미추론 시 생략

### 노면 클래스 (5종 + 기타) — ✅ 자전거도로 추가
| 코드(`RoadClass`, Pi 내부) | 표시명(앱·파일명) | 위험도 |
| --- | --- | --- |
| `asphalt` | 아스팔트 | 안전 |
| `bike_path` | **자전거도로** | 안전 |
| `sidewalk_block` | 보도블럭 | 주의 |
| `concrete` | 콘크리트 | 주의 |
| `gravel` | 비포장 | 위험 |
| `unknown` | 기타 | 위험(fail-safe 감속) |

- 앱 `FileFragment.roadTypes`에 **"자전거도로" 추가** — ✅ **완료 2026-08-26**(도현, PR #27). 순서: 아스팔트·자전거도로·보도블럭·콘크리트·비포장·기타
- Pi는 `RoadClass`↔표시명 매핑 테이블 보유(`pi/comm/protocol.py`). `unknown`은 policy에서 감속

### 에러·연결
- 연결 끊김 감지 → Pi **즉시 모터 정지**(§6). 재접속 대기
- 파싱 실패·미지 명령 → `{"type":"ERROR","cmd":"?","message":"..."}` 응답 후 무시
