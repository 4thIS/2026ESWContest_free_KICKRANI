# RPi 구현 계획 (Implementation Plan)

> 제24회 임베디드SW경진대회 자유공모 · 예선 마감 **2026-09-03**
> 설계 근거: [`설계명세서.md`](설계명세서.md) — 이 계획은 그 스펙을 서브시스템 단위로 쪼갠 실행 목록이다.
> 체크(`- [x]`)는 **실제 파일·테스트로 확인된 것만**. 근거: `work/공모전/임베디드/rc_car`(구동·속도제어 목 검증 완료, `py -m pytest -q` → 36 passed, 2026-07-20).

**목표:** 라즈베리파이 5 한 대가 **① 구동 · ② 속도제어 · ③ 데이터수집 · ④ 앱통신**과 **노면 인지**를 모두 담당하는 적응형 속도제어 킥보드(RC카 모형)를 완성한다. 진동(IMU)으로 노면을 실시간 판별해 위험 노면이면 자동 감속한다.

**아키텍처:** 4개 서브시스템 + 인지를 **각각 독립 모듈**로 개발(계약만 공유) → **통합 계층(controller)** 이 모드별(IDLE/COLLECT/DEMO)로 배선. 단일 프로세스 · 3 스레드(Sampler / Controller / BLE) + 2 큐(`sample_queue`, `command_queue`).

**기술 스택:** Python 3 · `smbus2`(I2C) · `gpiozero`+`lgpio`(GPIO/PWM) · `tflite-runtime`(추론) · `bluezero`(BLE) · `numpy` · `pytest`. 학습은 PC(오프라인), Pi는 추론만.

---

## Global Constraints (전 파트 공통)

- **안전 최우선:** 움직이는 차량. STOP / 연결끊김 / 에러 / 종료 시 **항상 모터 먼저 정지**. 불확실하면 감속/정지. 모터 기본상태 = 정지.
- **독립 개발 → 통합:** 각 서브시스템은 서로의 **계약(인터페이스)만** 알고 내부는 모른다. 하드웨어는 프로토콜/목으로 추상화해 PC에서 단위테스트.
- **TDD:** 실패 테스트 → 최소 구현 → 통과 → 커밋. 작은 단위로 자주 커밋. 접두어 `feat:`/`fix:`/`test:`/`docs:`/`chore:`.
- **개발 OS:** 팀원 Windows. 순수 로직은 Windows에서 `pytest`, 실제 GPIO/I2C/BLE는 Pi 5(SSH)에서 검증.
- **소유자 표기:** 각 태스크에 `[DJ]`(동제·구동/속도) · `[CW]`(찬우·수집/인지/앱통신) · `[공동]`. 남의 폴더·공통 계약 변경은 담당자 합의 후.
- **200Hz 샘플링:** 노면 고주파 정보(자갈길 등)를 담기 위한 나이퀴스트 근거. MPU FIFO로 지터 흡수. DLPF 94Hz 안티에일리어싱.
- **파일 배치:** `RPi/pi/` 아래. `sensors/` `motion/` `collect/` `infer/` `comm/` `controller.py` `main.py` `config.py` (설계명세서 예정 구조).
- **⭐ 설계명세서가 유일 기준(single source of truth):** 인터페이스 계약(§2·서브시스템 명세)·핀맵(§8)·상태전이(§5)·데이터규격(§7)은 모두 **설계명세서를 따른다**. 기존 `rc_car/src` 코드는 이 계약·핀맵에 **맞춰 수정한 뒤** `RPi/pi/`로 이식한다. 불일치는 예외 없이 **설계명세서 우선**.

- [ ] **Step 1: 계약 정의** (설계명세서 §2)

```python
# RPi/pi/contracts.py
from typing import TypedDict, Literal, Protocol, Callable

class Sample(TypedDict):
    t_ms: int
    ax: int; ay: int; az: int
    gx: int; gy: int; gz: int
    wheel_pulse: int

RoadClass = Literal["asphalt", "bike_path", "sidewalk_block", "concrete", "gravel"]
Mode = Literal["IDLE", "COLLECT", "DEMO"]

# ── 서브시스템 인터페이스(Protocol) — 각 파트가 구현, 통합이 소비 ──
class Motor(Protocol):                    # ①
    def set_duty(self, duty: float) -> None: ...   # 0.0~1.0 직진
    def stop(self) -> None: ...

class SpeedController(Protocol):          # ②
    def set_target(self, speed: float) -> None: ...
    def update(self) -> None: ...          # 주기 호출: 엔코더→Motor 보정
    def stop(self) -> None: ...

class Sampler(Protocol):                  # ③
    def start(self) -> None: ...           # FIFO drain+엔코더 → sample_queue
    def stop(self) -> None: ...

class Logger(Protocol):                   # ③
    def open(self, label: str) -> None: ...
    def write(self, s: Sample) -> None: ...
    def close(self) -> None: ...

class BleServer(Protocol):                # ④
    def on_command(self, cb: Callable) -> None: ...
    def send_telemetry(self, data: dict) -> None: ...
    def start(self) -> None: ...
```
