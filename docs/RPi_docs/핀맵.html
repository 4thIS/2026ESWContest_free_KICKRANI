Raspberry Pi 5 핀맵

최종 부품(L298N · KY-003 래치형 홀센서 · MPU-6050) 기준으로 40핀 헤더에서 실제 쓰는 핀만 표시. 색이 역할이다. 물리핀 번호 = 헤더에 꽂는 실제 자리.

🛑 2026-08-24 변경 — 홀센서 배선이 바뀌었다. A3144 베어 소자 + 10kΩ 풀업 계획은 폐기. 실물은 KY-003 래치형(풀업 내장)이며 3.3V(물리 17) 급전 · S 직결 · 외부 풀업 없음이다. 엔코더 핀 = GPIO22(물리 15) — 물리 11(GPIO17)은 손상돼 사용 금지. 문서 하단 조립 절차의 A3144 그림·표는 폐기된 계획의 기록이다.

배선 순서 (A3 조립)

위 표가 무엇을 어디에라면, 아래는 어떤 순서로다. 순서에는 이유가 있다 — 접지 먼저 · 전원 다음 · 신호 마지막, 그리고 각 단계마다 검증하고 다음으로. 한 번에 다 꽂고 전원을 넣으면 뭐가 잘못됐는지 못 찾는다. 작업 중에는 그림 2(L298N 단자 지도)를 옆에 띄워두면 편하다. 준비물: 멀티미터(도통·전압) · 점퍼선 · 납땜 도구 · 바퀴를 띄울 받침대.

  1. 사전 작업 — 전원 전부 차단한 상태에서

    • 2S 배터리 분리 · Pi USB-C 분리. 9단계까지 전원은 들어가지 않는다.
    • L298N ENA·ENB 점퍼캡 뺀다 · 5V EN 점퍼는 꽂아둔다.
    • L298N 칩에 방열판 부착. 배선이 다 붙으면 손이 안 들어간다 — 지금 한다.
    • 구동륜 1개에만 자석 4개를 90°마다(그림 3). ⚠️ 재정정(2026-08-24): 실물 모듈(KY-003)이 래치형 → N-S-N-S 극성 교대로 붙여야 토글된다(같은 극만이면 첫 자석에서 잠김). 상승엣지 카운트 기준 회전당 2펄스 예상 — calibrate_encoder.py로 실측 확정.
    • 차체를 받침대에 올려 바퀴를 공중에 띄운다. 이 상태를 끝까지 유지한다.

  2. 공통 접지 — 제일 먼저 묶는다

    • 2S 배터리 (−) ↔ L298N GND ↔ Pi 14 를 하나로.
    • 왜 먼저인가: 신호선을 먼저 꽂고 GND를 나중에 묶으면, 기준 전위가 없는 동안 전류가 신호선(GPIO)을 통해 흐른다. 이게 GPIO를 태우는 가장 흔한 경로다.
    ✅ 검증 — 멀티미터 도통 모드로 Pi 14번 ↔ L298N GND ↔ 배터리 (−)가 전부 삐 소리. 하나라도 안 울리면 다음으로 넘어가지 않는다.

  3. 모터 전원부 — 배터리 → L298N

    • 1000µF 먼저. 흰 띠 쪽이 (−) → L298N GND, 반대쪽이 (+) → 12V(VMS). 전원 단자에 최대한 가깝게.
    • 배터리 (+) → L298N 12V(VMS). 전원선은 굵게.
    • ⚠️ 전해콘덴서를 거꾸로 꽂으면 터진다. 배터리 물리기 전에 극성을 두 번 본다.
    ✅ 검증 — 배터리 연결 → L298N 5V 단자와 GND 사이가 약 5V. 안 나오면 5V EN 점퍼가 빠진 것이다. 확인했으면 배터리를 다시 뺀다.

  4. 모터 4개 → OUT 단자

    • 좌측 앞·뒤 모터 2개를 병렬로 묶어 OUT1 / OUT2.
    • 우측 앞·뒤 모터 2개를 병렬로 묶어 OUT3 / OUT4.
    • 같은 쪽 2개는 반드시 같은 방향으로 돌아야 한다. 좌우 모터는 서로 마주보게 장착되므로 한쪽은 배선을 뒤집게 되는 게 정상이다 — 실제 확인은 5단계에서 한다.

  5. 방향 고정 (IN1~IN4) + 회전 방향 검증

    • IN1 · IN3 → L298N 보드 +5V 단자.
    • IN2 · IN4 → L298N GND. (Pi GPIO는 안 쓴다 — 직진 전용)
    • ⚠️ 지금 ENA·ENB는 아무 데도 안 물린 플로팅 상태라 동작이 정해져 있지 않다. 바퀴 공중을 반드시 유지.
    ✅ 검증 — 배터리 연결 → 점퍼선으로 ENA를 보드 +5V에 잠깐 댄다. 좌측 2바퀴가 함께 전진 방향으로 돌아야 한다. ENB도 동일.
    · 한 바퀴만 반대 → 그 모터의 OUT 두 선을 맞바꾼다
    · 두 바퀴 다 반대 → IN1↔IN2(우측이면 IN3↔IN4)를 맞바꾼다
    확인 끝나면 배터리를 뺀다.

  6. Pi → L298N 신호선 — 배터리 뺀 상태에서

    • Pi 12 (GPIO18) → L298N ENA (좌)
    • Pi 33 (GPIO13) → L298N ENB (우)
    • Pi의 3.3V로 L298N 입력을 구동할 수 있다(VIH 2.3V) — 레벨 시프터 불필요.
    ⚠️ L298N 5V 단자는 출력이다. Pi의 5V·3.3V 어디에도 연결하지 않는다. 두 전원이 맞붙는다.

  7. MPU-6050 (자이로·가속도)

    • VCC→1(3.3V) · GND→6 · SDA→3 · SCL→5 · AD0→GND(주소 0x68).
    • 차체에 리지드 마운트. 이 센서가 읽는 진동이 곧 노면 판별 입력이다 — 물렁한 양면테이프나 늘어진 배선에 매달면 진동이 뭉개져 C1 수집 데이터 자체가 못 쓰게 된다. 장착 위치·방향은 조립 후 고정하고 바꾸지 않는다(바꾸면 재수집).
    ✅ 검증 — Pi 켜고 i2cdetect -y 1 → 68이 뜬다. 안 뜨면 SDA/SCL 뒤바뀜 또는 I2C 미활성(raspi-config)을 먼저 의심.

  8. 홀센서 (KY-003 래치형) — 가장 조심할 단계

    🛑 아래 "A3144 + 10kΩ 풀업" 배선은 폐기됐다 (2026-08-24). 실물이 KY-003 래치형 모듈(풀업 내장)이라 그 배선을 그대로 하면 DO가 5V로 나와 GPIO가 손상된다. 실제로 GPIO17(물리 11)이 손상됐고, 엔코더 핀을 GPIO22(물리 15)로 옮겼다. 경위: 홀센서_트러블슈팅.md
    ✅ 현재 확정 배선 — VCC→17(3.3V) · GND→9 · S(신호)→15(GPIO22) 직결. 외부 풀업 저항 없음(모듈 내장). 물리 11 사용 금지 · 5V 급전 금지. 자석은 N-S 교대 4개 → 상승엣지 기준 ENCODER_PULSES_PER_REV = 2(실측 확정), 소프트웨어 디바운스 10ms.
    • 센서와 자석 간격 1~3mm, 자석이 센서 정면을 스치도록 위치를 잡는다(그림 3).
    • 핀 배열: 마킹된 평평한 앞면을 보고 왼쪽부터 1=VCC · 2=GND · 3=OUT — 베어 소자 A3144 기준. KY-003 모듈은 실크 인쇄(-/middle/S)를 따른다.
    • VCC→4(5V) · OUT→11(GPIO17) — 폐기(위 확정 배선 참고)
    • 10kΩ을 OUT ↔ 1(3.3V) 사이에 넣는다 — 폐기(모듈 풀업 내장)

    아래 그림은 폐기된 A3144 베어 소자 계획의 기록이다. 실제 배선은 위 "현재 확정 배선"을 따른다.

    ⚠️ 풀업을 5V에 물리면 안 된다. DO 하이가 5V로 나와 Pi GPIO가 손상된다. VCC만 5V, 풀업은 3.3V — 이게 이 부품의 전부다. 같은 이유로 풀업 내장 3핀 모듈은 쓰지 않는다(전원계산.md §7-7).
    ✅ 검증 — GPIO22를 읽으면서 자석을 갖다 대면 레벨이 토글된다. KY-003은 래치형이라 한쪽 극에서 ON으로 걸리고 반대 극을 대야 OFF로 풀린다 — 그래서 바퀴 자석은 N-S 교대로 붙인다. 반응이 없으면 자석을 뒤집어 다시 시도. 바퀴를 손으로 한 바퀴 돌려 상승엣지 2펄스(실측 확정 ENCODER_PULSES_PER_REV=2)가 세어지는지 확인 → 그대로 B6(엔코더 실측 보정)로 이어진다.

  9. 첫 통전 — 넣는 순서 · 끄는 순서

    • 넣기: ① 바퀴 공중 재확인 → ② Pi USB-C 연결 → ③ setup_check.py(기본 실행은 모터 안 돎) → ④ 모터 배터리 연결 → ⑤ setup_check.py --pwm → ⑥ --jitter(ENA→GPIO27 점퍼).
    • 끄기는 역순: 모터 배터리 먼저 분리 → 그다음 Pi sudo shutdown -h now. Pi를 먼저 끄면 PWM 핀이 뜨면서 모터가 어떻게 될지 모른다.
    ⚠️ 지금 코드는 DUTY_MAX=1.0이고 소프트스타트·스톨감지가 없다(전원계산.md §3가 요구한 4중 대응 중 2개 미구현). 스톨 시 채널당 2.4A로 L298N 연속정격(2A)을 넘긴다.
    → 첫 통전에서는 짧게·저듀티로만 돌리고, 바퀴가 막힌 채로 듀티를 물고 있지 않는다. 지면 주행(B7)은 이 3개가 코드에 들어간 뒤에 한다.

절대 하지 말 것

  • Pi 물리 2번(5V)에 급전 금지. Pi는 USB-C PD로만 급전한다. 5V 핀 급전은 PMIC 보호를 우회하며, USB-C와 동시에 넣으면 두 전원이 맞붙는다.
  • L298N 5V 단자를 Pi에 연결 금지. 그건 출력이다.
  • A3144 풀업을 5V로 금지, 3핀 풀업내장 모듈 금지. 둘 다 결과는 GPIO 손상.
  • 전원 넣은 채 배선 변경 금지. GND는 맨 처음 꽂고 맨 마지막에 뺀다.
  • 바퀴를 땅에 댄 채로 첫 통전 금지. 방향이 반대면 그대로 튀어나간다.
