🔌 L298N 배선 가이드 — 4WD 직진 전용

노면 감지 킥보드 · 근거: 설계명세서 §8 · 전원계산.md · 보드: LCKFB L298N (78M05 내장)
⚠️ 작업 전 필수
① 배터리를 분리한 상태에서 모든 배선을 한다 · ② 배선 완료 후 육안 재점검 → 그다음 전원 인가
③ 첫 구동은 반드시 바퀴를 공중에 띄우고 저속(30%)부터

1. 전체 결선 개요

   [2S 18650 · 7.4V]                      [USB PD 보조배터리 5V/3A↑]
        │  +                                        │
        │  └──[1000µF]──┐                           │ USB-C
        │  −            │                           ▼
        ▼               ▼                    ┌─────────────┐
   ┌──────────────────────────┐              │  라즈베리파이 5  │
   │   L298N 모터 드라이버      │              │              │
   │  VS  ← 배터리 +           │              │  GPIO18(12번)├──→ ENA
   │  GND ← 배터리 − ──────────┼──── 공통 ────┤  GPIO13(33번)├──→ ENB
   │  VSS → (5V 출력)          │     GND      │  GND (6번)   │
   │                          │              └─────────────┘
   │  IN1 ← VSS(5V)  ┐        │
   │  IN2 ← GND      │ 전진   │   ⚠️ 이 4개는 L298N 보드 안에서
   │  IN3 ← VSS(5V)  │ 고정   │      자체 점퍼선으로 연결
   │  IN4 ← GND      ┘        │
   │                          │
   │  OUT1/OUT2 → 좌측 모터 2개 │
   │  OUT3/OUT4 → 우측 모터 2개 │
   └──────────────────────────┘
왜 IN 핀을 고정하나? 이 프로젝트는 조향이 없고 직진/정지만 한다(설계명세서 §8). 방향을 하드웨어로 고정하면 Pi는 속도(ENA·ENB PWM)만 제어하면 되고, GPIO 4개를 아낀다.

2. 점퍼 설정 — 가장 많이 틀리는 부분

점퍼설정이유
5V-EN
(5V 활성)		 꽂는다 (ON) 배터리 7.4V가 7~12V 범위라 보드의 78M05 레귤레이터가 5V를 만든다.
이 5V가 VSS 핀으로 나오고, 우리는 이걸 IN1·IN3에 쓴다.
ENA 점퍼캡
ENB 점퍼캡		 반드시 뺀다 (OFF) 꽂혀 있으면 ENA/ENB가 5V에 직결되어 항상 최고속 고정.
Pi의 PWM이 완전히 무시된다 → 속도제어 불가
⚠️ 모터가 안 돌거나 / 전속력으로만 돈다면 십중팔구 이 점퍼 문제다.
· 안 돎 → 5V-EN 빠져 있어 VSS에 5V가 없음 (IN 핀에 신호 없음)
· 최고속 고정 → ENA/ENB 점퍼캡이 안 빠짐

3. 배선표

3-1. 전원 (터미널 블록 — 나사 조임)

L298N 단자연결 대상비고
VS (VMS/12V)2S 18650 + (7.4V)+ 단자 옆에 1000µF 전해콘덴서 병렬(극성 주의)
GND2S 18650 −
+ Pi GND		⚠️ Pi GND와 반드시 공통 — 아래 §5 참고
VSS (5V)출력 — IN1·IN3에 공급❌ Pi 전원으로 쓰지 말 것(0.5A, 설계명세서 §8 금지)

3-2. 방향 고정 — L298N 보드 자체 점퍼선 4개

출발도착결과
VSS (5V)IN1좌측 채널 전진 고정
GNDIN2
VSS (5V)IN3우측 채널 전진 고정
GNDIN4
바퀴가 뒤로 돌면 그 채널의 IN 두 개를 서로 바꾼다(예: IN1↔IN2). 모터 출력선(OUT)을 바꿔도 되지만, IN 쪽이 더 쉽다.

3-3. Pi ↔ L298N 신호

Pi 물리핀BCM→ L298N역할
12번GPIO18ENA좌측 속도 PWM (1kHz)
33번GPIO13ENB우측 속도 PWM (1kHz)
6번 (또는 9·14·20…)GNDGND⚠️ 공통 접지 (필수)
핀 번호는 RPi/pi/config.py의 ENA=18 / ENB=13 단일 출처를 따른다. 배선을 바꾸면 이 파일만 수정하면 된다.

3-4. 모터 출력

L298N연결비고
OUT1 / OUT2좌측 모터 2개 병렬4WD라 채널당 모터 2개.
같은 쪽 모터는 같은 극성으로 묶어야 같은 방향으로 돈다
OUT3 / OUT4우측 모터 2개 병렬

4. 조립 순서

1
배터리 분리 확인 — 모든 배선은 무전원 상태에서
2
점퍼 설정 — 5V-EN 꽂기 / ENA·ENB 점퍼캡 빼기
3
IN 고정 점퍼 4개 — VSS→IN1, GND→IN2, VSS→IN3, GND→IN4
4
모터 4개를 OUT1/2·OUT3/4에 연결 (좌우 2개씩)
5
Pi 신호선 3개 — 물리 12→ENA, 33→ENB, 6→GND
6
배터리 + 콘덴서를 VS/GND에 (콘덴서 극성 확인!)
7
Pi는 USB-C 보조배터리로 별도 전원
8
바퀴 공중에 띄우고 → 테스트

5. ⚠️ 전원 격리 ≠ 접지 분리

전원 레일(VS·USB)은 분리하되, GND는 반드시 공통으로 묶는다.

Pi의 GPIO18/13이 L298N ENA/ENB로 나가는데, 기준 전위가 다르면 이 신호가 의미를 잃는다.
"전원 격리"를 GND까지 끊는 것으로 오해하면 아무것도 동작하지 않는다.

보드 문서 원문: "the microcontroller's GND must be connected to the module's GND"

6. 발열·보호

항목내용
방열판필수. 정상 1.2W/채널, 스톨 시 순간 ~9W/채널 → 없으면 열보호 셧다운(주행 중 정지)
DUTY_MAX0.75 권장 — 스톨 시 채널 2.4A로 연속정격(2A) 초과. 목표 듀티가 0.65~0.75라 성능 손실 없음
소프트스타트듀티 0→목표를 0.3~0.5초 램프 → 기동 돌입전류 억제
전압강하L298N은 ~2V 강하 → 배터리 7.4V면 모터엔 약 5.4V. 정상이다

7. 배선 후 검증

① 전원 인가 전 — 육안 체크

  • 5V-EN 점퍼 꽂힘 / ENA·ENB 점퍼캡 빠짐
  • IN1·IN3 → VSS(5V) · IN2·IN4 → GND
  • Pi GND ↔ L298N GND 연결됨
  • 1000µF 콘덴서 극성(− 줄무늬가 GND 쪽)
  • 배터리 +/− 방향

② 전원 인가 후 — 무구동 확인

ssh kick "pinctrl get 18,13"
# 기대: 둘 다 미할당(none) 또는 lo — 모터가 돌면 안 됨

③ 저속 구동 테스트 (⚠️ 바퀴 공중)

ssh kick "cd ~/embedded_kickboard/RPi && timeout 20 python3 -c \"
from pi.hardware.backend import get_gpio
from pi.motion.motor import Motor
import time
g=get_gpio(); m=Motor(g); m.stop()
for d in (0.30, 0.50):
    print(f'듀티 {d*100:.0f}%'); m.set_duty(d); time.sleep(2); m.stop(); time.sleep(1)
m.stop(); g.cleanup(); print('종료')
\""
성공 기준 — 30%에서 천천히, 50%에서 더 빠르게, 네 바퀴가 같은 방향으로 회전. 명령 종료 시 즉시 정지.

8. 문제 해결

증상원인조치
전혀 안 돎배터리 미연결 / 5V-EN 빠짐 / IN 고정 안 됨§2·§3-2 확인
항상 최고속ENA/ENB 점퍼캡빼기
한쪽만 돎해당 채널 IN 또는 OUT 배선좌우 비교
뒤로 돎IN 극성그 채널 IN 두 개 교체
돌다가 멈춤·뜨거움열보호 셧다운방열판 · DUTY_MAX=0.75
Pi가 리셋됨전원 공유 / GND 부실Pi는 USB-C 별도, 콘덴서 추가
약하게만 돎배터리 전압 낮음7.0V 이하면 충전(그 이하는 목표속도 미달 → 수집 데이터 오염)
