### Phase C — 데이터·모델 (W2~W3: 8/20~8/29)

- [ ] **C1** ⭐ 본 데이터 수집 `[공동, CW 주관]` — RC카로 노면 5종 × 세션 5개+ × 10~20초, 1주행=1파일. **의존: B5(수집 검증) · A1(성립) · B6·B7(정속 확보)**
  - ⚠️ **정속(B7) 없이 수집하면 안 된다.** 진동 특징 주파수는 대략 `속도 ÷ 요철간격`이라 **속도가 2배면 특징도 2배로 이동**한다(0.5초/200Hz 윈도우에 그대로 찍힘). 결과:
    1. 같은 노면인데 스펙트럼이 제각각 → 클래스 내 분산 폭증
    2. 더 위험 — 자갈길은 느리게, 아스팔트는 빠르게 몰게 되어 **노면 라벨과 속도가 상관** → 모델이 노면이 아니라 **속도를 학습**(shortcut). 검증 정확도는 높은데 DEMO에서 무너지고 원인 추적도 어려움
  - B7 없이는 **오픈루프 duty**라 노면 저항에 따라 속도가 변한다(자갈길에서 같은 duty로도 더 느려짐) → 위 2번이 자동으로 발생
  - DEMO는 policy가 노면→속도를 바꾸는 **피드백 루프**다. 학습이 정속 기준이 아니면 루프가 진동한다
  - 프로젝트 핵심 주장이 "수집=시연 동일 RC카 → **도메인 갭 0**"인데, 수집만 속도제어가 없으면 **바로 그 갭이 생겨 논리가 자기모순**이 된다
  - 권장: 수집 시 목표속도를 고정 구간(예: 0.3 / 0.4 / 0.5 m/s)으로 나눠 **라벨에 함께 기록** → C3(윈도우 비교)에 그대로 재사용

- [ ] **C3** 시간 vs 거리 윈도우 비교 실험 `[CW]` — 보고서 어필 포인트. **의존: C1**

## 5. 완료 기준 (Definition of Done)

1. 앱 START→RC카 정속주행→노면별 자동 감속→STOP이 **트랙에서 재현**된다 (영상 확보)
2. COLLECT 모드 CSV 결측 없음, 모델 세션단위 정확도 목표(≥70%) 달성
3. 안전 시나리오 전 항목 통과 (끊김·워치독·SIGTERM 모두 모터 정지)
4. 보고서 20p·영상 3분·Public 레포 — **9/1 제출 완료**
