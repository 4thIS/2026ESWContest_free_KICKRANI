# 임베디드 소프트웨어 공모전 - 노면 감지 킥보드 (도현, 명재, 동제, 찬우)

제24회 임베디드SW경진대회 자유공모 부문 출품작.

진동(IMU) 센서로 주행 중 **노면 재질을 실시간 판별**하고, 위험한 노면에서는 자동으로 **감속**,
안전한 노면에서는 정상 속도로 달리는 **적응형 속도제어 킥보드**.
데이터 수집과 시연을 모두 동일한 RC카(킥보드 모형)로 수행해 학습=배포 환경을 일치시킨다.

## 개요

- **노면 5종**: 아스팔트·자전거도로(안전) / 보도블럭·콘크리트(주의) / 자갈길(위험)
- **핵심 아이디어**: 카메라는 노면이 "어떻게 보이는지"를 보고, 진동은 "실제로 어떤지"를 느낀다 → 저전력·전천후·프라이버시 이점
- **플랫폼**: Raspberry Pi 5 (구동·수집·추론·통신 통합) + MPU-6050(진동) + A3144 홀센서(속도) + L298N(모터, 4WD)

## 팀
