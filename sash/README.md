# sash — RC카 섀시 · 외형 셸 · 시연 트랙

RC카 몸체·킥보드 외형·부품 마운트 관련 자료가 들어간다.

> 📌 **2026-08-24 결정 — 3D 프린팅 폐기, 기성 아크릴 RC카 모형 채택.**
> 제작 시간을 아끼고 마운트가 이미 있는 기성품을 쓰기로 했다. 섀시 프레임 자체를 출력하지 않으므로
> 이 폴더의 초점은 **외형 셸 · 부품 마운트 · 시연 트랙**으로 옮겨졌다.

## 내용

- **킥보드 모양 외형 셸** (아크릴 섀시 위에 덮는 형태) — 선택·시연 연출용 (R5-4)
- 부품 마운트: 라즈베리파이 · 모터/드라이버 · 배터리 · **센서(IMU) 홀더** · 바퀴 엔코더 자석 장착
- **시연 노면 트랙** (R5-3) — 아스팔트·보도블럭·자갈 샘플판. 부스 크기(2m×2m) 고려.
  **본 데이터 수집(R3-2)에도 그대로 쓰므로 빠를수록 좋다.**
- 시연 촬영 (R6-2)

## 파일 형식

- 셸·마운트를 출력하는 경우: `.stl`(프린팅용) / `.step`·`.f3d`·`.scad`(원본 CAD)
- 트랙·조립은 사진·치수 메모로 남겨도 된다

## 설계 유의사항

- **IMU는 셸이 아니라 섀시(차체)에 리지드 마운트** — 바퀴 진동을 그대로 받아야 한다.
  **볼트+와셔로 고정하고 테이프는 쓰지 않는다**(유격·공진이 노면 신호를 오염시킨다 — 실행계획 리스크 항목)
- 무게중심 낮게(배터리 바닥), 커넥터·USB·전원 스위치 접근구 확보
- 수집·시연이 동일 차량이므로 센서 위치를 고정·재현 가능하게
