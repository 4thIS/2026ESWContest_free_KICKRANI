# sash — RC카 틀 (섀시) 3D 프린팅

RC카 몸체·킥보드 외형·부품 마운트의 **3D 프린팅 파일**이 들어간다.

## 내용 (예정)

- RC카 섀시(4WD) 프레임
- **킥보드 모양 외형 셸** (RC카 위에 덮는 형태)
- 부품 마운트: 라즈베리파이 · 모터/드라이버 · 배터리 · 센서(IMU) 홀더
- 바퀴·엔코더 자석 장착 부품

## 파일 형식

- `.stl` (프린팅용) / `.step` 또는 `.f3d`·`.scad` 등 (원본 CAD)

## 설계 유의사항

- **IMU는 셸이 아니라 섀시(차체)에 리지드 마운트** — 바퀴 진동을 그대로 받아야 함
- 무게중심 낮게(배터리 바닥), 커넥터·USB·전원 스위치 접근구 확보
- 수집·시연이 동일 차량이므로 센서 위치를 고정·재현 가능하게
